# encuentro-tecnologico-universitario

Proyecto académico ficticio para gestionar el registro y el cupo de un evento universitario.

## Problema y objetivo

### Problema
El registro de asistentes al Encuentro Tecnológico Universitario se realiza mediante mensajes y hojas de cálculo dispersas.
Esto puede generar registros duplicados y dificultar la consulta del cupo disponible.
La falta de un registro centralizado aumenta el riesgo de aceptar más asistentes que lugares disponibles.

### Objetivo medible
Registrar, en una prueba funcional, 100 asistentes con correos únicos y rechazar registros adicionales cuando se alcance el cupo de 100 lugares.

### Siguiente paso
Diseñar el formulario de registro y definir las validaciones de correo único y cupo máximo antes de implementar la aplicación.
